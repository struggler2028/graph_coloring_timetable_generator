# Sprint 1 – Sprint Planning

## 1. Sprint Overview

- **Project:** Dynamic Graph Coloring Based Exam Timetabling and Seating Plan Generator
- **Sprint:** Sprint 1 – Foundation and Planning
- **Duration:** Week 1
- **Methodology:** Agile Scrum
- **Sprint Status:** Planned

## 2. Sprint Goal

The primary goal of Sprint 1 is to establish the foundation of the examination timetabling system by analysing project requirements, designing the initial database structure, and preparing the user interface wireframes.

## 3. Sprint Objectives

- Understand the examination scheduling problem.
- Finalize the functional and non-functional requirements.
- Identify the required student, course, examination, and room information.
- Prepare the initial database design.
- Create basic UI wireframes.
- Plan the modules required for graph-based scheduling and seating allocation.

## 4. Sprint Scope

The following activities are included:

1. Requirement analysis.
2. Problem definition and project scope.
3. Identification of system inputs and outputs.
4. Initial database design.
5. User interface wireframe preparation.
6. Planning of system modules.

Graph-coloring implementation, room allocation, and seating-plan generation are excluded from this sprint.

## 5. Team Responsibilities

Team members will collaborate on requirement analysis, database planning, interface design, and documentation.

Individual task ownership and contributions will be recorded in the sprint backlog.

## 6. Expected Deliverables

- Finalized project requirements.
- Identified system inputs and outputs.
- Initial database schema.
- Basic UI wireframes.
- Initial system module plan.
- Updated project documentation.

## 7. Definition of Done

A task will be considered complete when:

- The required planning activity is completed.
- The output is reviewed by the team.
- Relevant documentation is updated.
- Any identified issue is recorded.
- The work is ready for the next sprint.

## 8. Sprint Outcome

The actual sprint outcome and completion status will be recorded after the sprint review.
