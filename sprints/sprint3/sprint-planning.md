# Sprint 3 – Room Allocation and Seating Plan Generation

## Sprint Duration
Week 3

## Sprint Goal
To allocate examination rooms based on room capacity, generate seating plans for students, and integrate these features with the existing timetable system.

## Sprint Objectives
- Assign rooms to examinations according to their student strength and room capacity.
- Ensure that room capacity is not exceeded.
- Allocate seats to students for each examination.
- Ensure that every student receives a valid seat allocation.
- Integrate room allocation and seating plan modules with the timetable system.
- Test the generated room allocations and seating plans.

## Sprint Scope
This sprint focuses on room allocation, seating arrangement, and backend integration.

Graph construction, conflict detection, and timetable generation are part of Sprint 2 and are not the main focus of this sprint.

## Expected Deliverables
- Room allocation module.
- Capacity validation.
- Student seating plan generator.
- Backend integration with the timetable.
- Test results for room and seating allocation.

## Sprint Status
Planned

Actual completion status will be updated after sprint execution and review.
