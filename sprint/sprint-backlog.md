**Total Story Points: 11**

## 2. Detailed Task Breakdown

### US-01: Requirement Analysis

- Understand the examination scheduling problem.
- Identify administrator requirements.
- List student, course, examination, and room inputs.
- Identify the expected timetable and seating-plan outputs.
- Define functional and non-functional requirements.
- Finalize the initial project scope.

### US-02: Database Design

- Identify the required database entities.
- Define the Student entity.
- Define the Course entity.
- Define the Examination entity.
- Define the Room entity.
- Identify relationships between students, courses, and examinations.
- Prepare the initial database schema.

### US-03: UI Wireframe Design

- Plan the administrator dashboard.
- Design student and course input screens.
- Design examination and room input screens.
- Plan the timetable display.
- Plan the conflict graph visualization area.
- Plan the seating-plan display and export section.

## 3. Acceptance Criteria

### US-01

- Project requirements are clearly documented.
- Required inputs and outputs are identified.
- Project scope is defined.

### US-02

- Main database entities are identified.
- Relationships between entities are defined.
- Initial database schema is prepared.

### US-03

- Basic wireframes are prepared.
- Main application screens are identified.
- Navigation between important sections is planned.
