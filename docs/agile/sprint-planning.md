# Sprint Planning Framework & Ceremonies

## 1. Overview
Sprint Planning is held at the beginning of each 1-week sprint to determine:
1. **The Sprint Goal:** The core value proposition to be delivered in the sprint.
2. **The Sprint Backlog:** The selected user stories pulled from the Product Backlog.
3. **Execution Strategy:** Technical breakdown into tasks, algorithm formulations, and testing targets.
